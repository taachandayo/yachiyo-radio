# たーちゃんの衒らかし用らじお

AIとテクノロジーの気になるニュースを、毎朝コンパクトにお届けするテスト放送局です。

- 形式：myradio（https://github.com/monoradio102/myradio、プログラムはMITライセンス）
- 台本：episodes/（CC0相当の運用。出典は各回のURLを参照）
- 声：AI音声合成（Muse）
- キャラクター：お手本の局のものを利用（AIで生成したキャラクターです）

## 聴き方

このフォルダを静的サーバーで配信すると、index.html のプレーヤーで再生できます。
GitHub Pages への公開手順は、元リポジトリの tools/publish.sh を参照。
